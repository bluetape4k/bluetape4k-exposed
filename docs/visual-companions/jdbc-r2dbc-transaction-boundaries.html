What remains true in every view

Keep infrastructure ownership visible

The application supplies the database, pool, dispatcher, timeout, and shutdown policy. A suspending API does not make blocking JDBC work non-blocking.

Do not overstate cancellation

Coroutine cancellation is not proof that rollback and connection return have already completed. Verify the selected driver, pool, Exposed, and framework combination.

Consume transaction-bound values in scope

JDBC DAO entities and lazy reads can require an active transaction. Map to detached values before crossing a boundary.

Keep external I/O outside rollback claims

HTTP calls, messages, and files are not undone by a database rollback. Use an outbox or another explicit delivery protocol.
