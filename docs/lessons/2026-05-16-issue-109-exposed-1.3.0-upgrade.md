# Issue #109 — JetBrains Exposed 1.3.0 업그레이드

**날짜**: 2026-05-16
**브랜치**: fix/issue-109
**PR**: (pending)

## 근본 원인

JetBrains Exposed 1.3.0이 출시됐지만 프로젝트는 `1.2.0`에 고정되어 있었다. 버전을 뒤처지게 유지하면 upstream bug fix와 새 dialect 지원을 채택할 수 없다.

## 결정

`gradle/libs.versions.toml`에서 `exposed = "1.2.0"`을 `"1.3.0"`으로 올린다. source 변경은 필요 없으며 version bump만으로 충분하다.

생태계 버전을 일관되게 유지하기 위해 `bluetape4k-dependencies/gradle/libs.versions.toml`도 갱신했다(PR bluetape4k-dependencies#27).

## 검증

```
./gradlew :exposed-core:build :exposed-jdbc:build :exposed-dao:build :exposed-r2dbc:build -x test
# 31초에 BUILD SUCCESSFUL, 213 tasks

./gradlew :exposed-core:test :exposed-jdbc:test :exposed-dao:test
# 309개 테스트 통과, 0 failed
```

## 교훈

- 지금까지 Exposed minor release는 source-compatible했으므로 patch/minor 업그레이드에는 version-only bump로 충분했다.
- consumer가 version catalog를 해석할 때 downstream drift가 생기지 않도록, 같은 release cycle에서 항상 `bluetape4k-dependencies`를 갱신한다.
- 다음 업그레이드 전에 https://github.com/JetBrains/Exposed/blob/main/CHANGELOG.md 의 Exposed changelog에서 breaking change를 확인한다.
