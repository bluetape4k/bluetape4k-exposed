# Issue #109 — JetBrains Exposed 1.3.0 Upgrade

**Date**: 2026-05-16  
**Branch**: fix/issue-109  
**PR**: (pending)

## Root Cause

JetBrains Exposed 1.3.0 was released. The project was pinned to `1.2.0`.
Staying behind blocks adoption of upstream bug fixes and new dialect support.

## Decision

Bump `exposed = "1.2.0"` → `"1.3.0"` in `gradle/libs.versions.toml`.
No source changes were required — the version bump alone is sufficient.

Also updated `bluetape4k-dependencies/gradle/libs.versions.toml` to keep the
ecosystem version consistent (PR bluetape4k-dependencies#27).

## Verification

```
./gradlew :exposed-core:build :exposed-jdbc:build :exposed-dao:build :exposed-r2dbc:build -x test
# BUILD SUCCESSFUL in 31s  213 tasks

./gradlew :exposed-core:test :exposed-jdbc:test :exposed-dao:test
# 309 tests passing, 0 failed
```

## Lessons

- Exposed minor releases have been source-compatible so far; a version-only bump
  is sufficient for patch/minor upgrades.
- Always update `bluetape4k-dependencies` in the same release cycle to prevent
  downstream drift when consumers resolve the version catalog.
- Watch the Exposed changelog at https://github.com/JetBrains/Exposed/blob/main/CHANGELOG.md
  for breaking changes before the next upgrade.
