# 2026-07-31 — 전체 페이지 시각화 캡처의 대형 이미지 처리

## 배경

Spring Boot Exposed 활성화 시각화 자료는 매뉴얼의 아키텍처 다이어그램을
본문과 라이트박스에서 재사용한다. 원본 PNG는 3600×2400이라 브라우저에서는
정상으로 보였지만, 헤드리스 Chrome의 전체 페이지 캡처에서는 화면 밖에 있는
다이어그램 일부가 비거나 잘리는 현상이 발생했다.

## 결정

시각화 자료에는 원본 SVG를 출처로 유지하되, 전체 페이지 캡처용 대체 이미지는
1800×1200으로 최적화한 PNG를 사용한다. 캡처 시에는 모든 이미지를
`decode()`한 뒤 두 프레임을 기다리고, GPU 경로 차이를 제거하기 위해
헤드리스 Chrome을 `--disable-gpu`로 실행한다.

## 검증

- 한·영 문서의 라이트·다크 캡처 4개를 각각 원본 크기로 확인했다.
- 동일 문서를 두 번 캡처해 크기와 SHA-256이 일치하는지 검증했다.
- 아키텍처 다이어그램 두 개의 라이트박스 열기와 닫기를 브라우저 감사로 확인했다.
- 7개 시퀀스의 28개 메시지에서 연결점 오차, 화살촉 색상, 반환 방향을 검사했다.

## 재사용 지침

전체 페이지 시각화에 대형 이미지를 포함할 때는 브라우저 화면 표시만으로
완료를 판단하지 않는다. 공개할 모든 로케일·테마 캡처를 생성해 원본 크기로
검토하고, 화면 밖 래스터 결함이 있으면 원본 출처는 유지하면서 캡처용
대체 이미지 크기를 조정한다.
