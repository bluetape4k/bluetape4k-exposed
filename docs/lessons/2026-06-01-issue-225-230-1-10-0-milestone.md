# 2026-06-01 exposed 1.10.0 milestone work

## Context

1.10.0 milestone 작업으로 `bluetape4k-bom:1.10.0` 참조와 함께 Spring Boot cache health,
BigQuery dry-run/options, Trino JDBC options, migration smoke, database examples를 한 브랜치에서 정리했다.

## Decision

- Spring Boot 4 health API는 `spring-boot-health`의 `org.springframework.boot.health.contributor.*`를 사용한다.
- BigQuery dry-run은 실제 credential 없이 `QueryRequest`를 캡처하는 단위/예제 테스트로 검증한다.
- Trino pushdown smoke는 Exposed `exec` 대신 JDBC `Statement.executeQuery`로 `EXPLAIN` 결과를 읽는다.
- demo migration smoke는 생성 결과가 체크인된 파일과 drift 없는지만 확인한다.
