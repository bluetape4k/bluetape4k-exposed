# 2026-06-01 Exposed 1.10.0 Milestone 작업

## 배경

1.10.0 milestone 작업으로 `bluetape4k-bom:1.10.0` 참조와 함께 Spring Boot cache health,
BigQuery dry-run/options, Trino JDBC options, migration smoke, database example을 한
branch에서 정리했습니다.

## 결정

- Spring Boot 4 health API는 `spring-boot-health`의
  `org.springframework.boot.health.contributor.*`를 사용합니다.
- BigQuery dry-run은 실제 credential 없이 `QueryRequest`를 capture하는 unit/example
  test로 검증합니다.
- Trino pushdown smoke는 Exposed `exec` 대신 JDBC `Statement.executeQuery`로 `EXPLAIN`
  result를 읽습니다.
- demo migration smoke는 생성 result가 check-in file과 drift가 없는지만 확인합니다.
