# Issues #129, #130, #138 - English KDoc 정리

## 배경

여러 Kotlin file에 최근 behavior fix 뒤에도 Korean KDoc이 남아 있었습니다. 이
repository의 public API와 contributor-facing documentation은 English여야 합니다.

## 결정

runtime code를 바꾸지 않고 target class KDoc, public API KDoc, 그리고
`DeclaredExposedR2dbcQuery`에서 명시적으로 요청된 inline comment를 English로
전환합니다.

## 결과

target KDoc은 이제 PartTree query execution, declared R2DBC query constraint,
Caffeine repository extension point를 English로 설명합니다.

## 검증

target file의 `/** ... */` KDoc block 안 Korean text를 모두 확인했고 Korean KDoc은
남아 있지 않습니다. `DeclaredExposedR2dbcQuery.kt`의 Korean text를 확인했고 결과가
없었습니다.

## 향후 지침

behavior fix가 public Kotlin API를 건드리면 issue를 닫기 전에 인접 KDoc을 scan해
language cleanup이 미뤄지지 않게 합니다.
