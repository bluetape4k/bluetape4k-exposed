# Catalog Ref 2026-05-25-01

## 배경

shared `bluetape4k-dependencies` catalog는 ASM, AWS Kotlin SDK, Apache Fory의 dependency
update를 받았습니다.

## 결정

기본 `bluetape4kDependenciesCatalogRef`를 floating `develop` 대신
`catalog/2026-05-25-01`에 pin합니다.

## 결과

Gradle settings는 이제 기본으로 release-train catalog를 fetch하면서
`bluetape4kDependenciesCatalogRef` 또는 `BLUETAPE4K_DEPENDENCIES_CATALOG_REF`를 통한
override도 허용합니다.

snapshot publish workflow는 `develop` checkout을 강제하는 대신 dispatched ref를 checkout해
branch-gated snapshot train validation이 통과한 동일한 catalog-pinned source를
publication합니다.

## 검증

- Settings file을 `catalog/2026-05-25-01`로 업데이트했습니다.
- `./gradlew compileTestKotlin --refresh-dependencies --console=plain -PsnapshotVersion=-SNAPSHOT`
- `actionlint .github/workflows/publish-snapshot.yml`

## 향후 guard

coordinated dependency train update에는 dated catalog tag를 사용합니다. manually
dispatched snapshot publish workflow에서 `develop` checkout을 강제하지 말고 dispatch ref를
사용해 validation과 publication이 같은 source tree를 사용하게 합니다.
