# Issue #694 Driver Benchmark 구현 계획

> **For agentic workers:** 이 계획을 별도 세션에서 수행할 때는 승인된 범위를 유지하고,
> 각 task의 RED/GREEN·raw evidence·scope 검사를 다시 확인한다.

**Goal:** PostgreSQL과 MySQL 8 실제 JDBC driver에서 Virtual Thread key enumeration의
sequential/parallel throughput, pool lease, query cleanup을 같은 matrix로 측정하고
재현 가능한 raw JSON·중앙값·EN/KO 차트를 남긴다.

**Architecture:** production `exposed/jdbc` API는 수정하지 않는다. benchmark module의
main source에는 Docker 없는 internal matrix/range helper만 두고, benchmark source의
fixture가 shared `Containers`와 `TestDB` credential을 재사용한다. 새 JMH class가
Hikari-tracked DataSource와 caller-owned Virtual Thread executor를 trial 단위로 소유하며,
PostgreSQL/MySQL Gradle configuration을 분리한다.

**Tech Stack:** Kotlin, JUnit 5, bluetape4k assertions, kotlinx-benchmark/JMH 1.37,
JetBrains Exposed JDBC, HikariCP, PostgreSQL/MySQL Testcontainers, Java 25 Virtual Threads,
Gradle, Detekt, CairoSVG.

## Task 4 — 순차 driver benchmark 증거

- [ ] Set `TESTCONTAINERS_RYUK_DISABLED=true`, inherit the managed Docker socket export, and
  verify `colima status`, `docker context show`, and `docker info` before container execution.
- [ ] Execute each driver-specific task three times, one process at a time. PostgreSQL and
  MySQL may not overlap; after the first invocation has identified the plugin's report path,
  copy that exact JMH JSON to a run-numbered destination before the next invocation. The
  capture loop must fail on a missing source, an existing destination, or a second JSON result.

```bash
for run in 1 2 3; do
  TESTCONTAINERS_RYUK_DISABLED=true ./gradlew :benchmark-exposed-benchmark:benchmarkJdbcDriverPostgreSQLBenchmark \
    --rerun-tasks --no-build-cache --no-configuration-cache \
    --no-parallel --max-workers=1 --console=plain
  python3 docs/benchmarks/exposed-benchmark-2026-08-22-issue-694/capture_jmh_run.py \
    --report-dir "$JMH_POSTGRES_REPORT_DIR" \
    --destination "docs/benchmarks/exposed-benchmark-2026-08-22-issue-694/postgresql-run-${run}.json" \
    --metadata "docs/benchmarks/exposed-benchmark-2026-08-22-issue-694/raw-metadata.jsonl" \
    --driver POSTGRESQL --run-id "$run" --git-sha "$(git rev-parse HEAD)"
done

for run in 1 2 3; do
  TESTCONTAINERS_RYUK_DISABLED=true ./gradlew :benchmark-exposed-benchmark:benchmarkJdbcDriverMySQLBenchmark \
    --rerun-tasks --no-build-cache --no-configuration-cache \
    --no-parallel --max-workers=1 --console=plain
  python3 docs/benchmarks/exposed-benchmark-2026-08-22-issue-694/capture_jmh_run.py \
    --report-dir "$JMH_MYSQL_REPORT_DIR" \
    --destination "docs/benchmarks/exposed-benchmark-2026-08-22-issue-694/mysql-run-${run}.json" \
    --metadata "docs/benchmarks/exposed-benchmark-2026-08-22-issue-694/raw-metadata.jsonl" \
    --driver MYSQL_V8 --run-id "$run" --git-sha "$(git rev-parse HEAD)"
done
```

driver-specific report directory로 고정한다. 각 디렉터리는 `capture_jmh_run.py`가
최상위 regular JSON 하나만 찾을 때만 통과하며, 여섯 destination은 실행 전에 존재하지
않아야 한다.
